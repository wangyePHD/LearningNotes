# 📅 研习复盘与周报生成 (Review & Synthesis) 细粒度编写规范

当用户让 Agent 生成周报、日报或阶段性科研复盘时（例如：“总结本周笔记”、“帮我生成第 38 周研习周报”），Agent 必须遵循本规范自主完成数据检索、高维综述与文件注册。

---

## 1. 扫描与检索工作流 (Step-by-Step Scan)

```text
[接收指令："总结本周研习成果"]
       │
       ▼
[步骤 1] 确定目标周期 (例如当前所在周：2026-W38)
       │
       ▼
[步骤 2] 检索本周期所有新写或更新的笔记文件
       - 优先通过 git log 检索过去 7 天变更的文件：
         `git log --since="7 days ago" --name-only --pretty=format:"" | sort -u`
       - 读取这些 Markdown 的标题、标签、公式与核心结论容器（::: tip）
       │
       ▼
[步骤 3] 深度提炼，绝非简单的“目录罗列”，必须形成学术级综述
       │
       ▼
[步骤 4] 写入 docs/reviews/YYYY-Wxx.md，并更新 docs/reviews/index.md 与侧边栏
```

---

## 2. 结构大纲标准 (强制包含 5 个小节)

```markdown
# YYYY 年第 WW 周研习周报：[提炼本周最有代表性的研究主题]

> **周期**：YYYY-MM-DD ~ YYYY-MM-DD  
> **整理人**：Ye Wang (王冶) & AI Agent  
> **涵盖笔记**：N 篇 · **核心标签**：`标签1` `标签2` `...`

---

## 1. 本周主攻方向与全景
- 提炼本周的研习脉络（例如：从某理论出发，经过什么公式推导，最终在某硬件/代码上完成验证）。

## 2. 核心理论推导与数学精华
- 严选 2~3 个最具代表性的核心公式，附带精炼的物理/几何直觉；
- 保留关键公式块（$$ ... $$）与收敛条件。

## 3. 算力工程与实战收获
- 汇总本周的实验数据、GPU 显存占用、吞吐量或并行通信瓶颈；
- 推荐使用 Markdown 对照表格，直观呈现调优前后对比。

## 4. 交叉灵感与 Idea 涌现
- 检视本周在 `docs/ideas/index.md` 中新增的假说，或总结在不同模态（如视频与 LLM 强化学习）碰撞产生的火花。

## 5. 下周待攻坚课题 (Next Week Backlog)
- 使用待办复选框列出 3~4 个下阶段亟待推导的数学公式、待复现的代码或待验证的猜想：
  - [ ] 课题一
  - [ ] 课题二
```

---

## 3. 自动归档维护

文件保存后，Agent 必须自动更新以下两处：
1. **`docs/reviews/index.md`**：在「历史周报归档」表格最上方追加新周报行；
2. **`docs/.vitepress/config.mts`**：在 `sidebar['/reviews/']` 中追加该周报的导航项。
