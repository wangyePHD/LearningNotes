# AI Agent 自动研习与笔记生成主协议 (Master Protocol)

本协议适用于本知识库中的所有 AI Agent。

## 1. 核心原则：内容忠实

- **用户提供什么，就记录什么。** 不扩写、不补充、不做额外检索、不添加未提供的公式/数据/结论/例子。
- **保留用户提供的结构与措辞。** 不套用固定模板；不为了“完整”增加章节。
- **不自动维护索引、侧边栏、标签池。** `docs/<domain>/index.md`、`docs/.vitepress/config.mts`、`docs/.vitepress/components/TagMatrix.vue` 仅在用户明确要求时更新。
- **不自动运行构建。** 仅在用户明确要求时运行 `npm run build`。
- **存放位置**：根据内容选择 `docs/domains/<domain>/` 或 `docs/foundations/`、`docs/infra/` 等合适目录；位置选择不等于扩写内容的许可。

## 2. 领域规范

`.agent/specs/` 下的领域规范仅作为**可选的写作参考**，不再要求“必须包含 N 个小节”。如果用户提供了内容或结构，以用户输入为唯一依据；如果用户明确要求按某个模板整理，再使用他指定的结构。

## 3. 格式

如果用户提供的内容本身包含 Markdown / LaTeX，可以按原样保留并做最小排版修正。不要为了套用格式而增加内容。不要写空洞的宣传型文字。
