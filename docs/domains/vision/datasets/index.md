## 1. 现代图像 AIGC 数据金字塔演进

现代顶级图像生成模型（如 SeFi-Image、Qwen-Image、Z-Image、FLUX）的模型能力演进，本质上是由不同阶段的数据梯次喂养驱动的：

```
                    ┌─────────────────────────┐
                    │  RLHF / Online RL 阶段   │  ~数千至数万级 Prompt + 奖励模型定向打标
                    │  (NFT / DPO / Flow-GRPO)│  主攻：文字拼写、瑕疵抑制、细粒度对齐
                    ├─────────────────────────┤
                    │    SFT 高审美微调阶段    │  ~10万 - 100万级（如 650K SFT集）
                    │  (High-Aesthetic / OCR) │  硬门槛过滤，极高画质/审美，多层结构化 Caption
                    ├─────────────────────────┤
                    │  持续训练/高分退火 (CT)  │  ~数百万 - 数千万级（如 Fine-T2I 9M）
                    │ (Continual / Annealing) │  全分辨率 (1024px+)，长难句 Caption，多域覆盖
                    ├─────────────────────────┤
                    │     大规模通用预训练      │  ~数亿 - 数十亿级（如 450M Recaption + 28M 合成）
                    │  (Massive Pre-training) │  多分辨率课程学习，三原则客观重标，字符级对齐
                    └─────────────────────────┘
```

## 3. 评测基准 (Evaluation Benchmarks)

除了训练数据集，图像 AIGC 的标准评估套件也是数据工程的核心分支：

- **细粒度指令遵循**：`GenEval`（单双主体、计数、颜色、空间关系、属性绑定）、`DPG-Bench`（800+ 复杂长 prompt）；
- **字符级文本渲染**：`CVTG-2K`（中英字符准确率、NED 编辑距离、Word Accuracy）；
- **长文本图文对齐**：`LongTextBench`（长段落、富信息多主体图文对齐，中英双语）；
- **综合通用质量**：`OneIG`（涵盖对齐、文本、推理、风格、多样性）、`Image Arena`（真人真实盲测胜率）。
