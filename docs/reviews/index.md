## 🤖 如何让 Agent 为你自动生成复盘周报？

你不需要自己动手摘抄汇总，在终端中直接对你的 Agent 说：

> 🗣️ **向 Agent 下达指令示例**：  
> - *“帮我复盘本周的所有笔记，总结在视频生成和 CUDA 优化上的核心收获，生成第 38 周周报。”*  
> - *“总结我今天记录的所有推导，在 docs/reviews/ 下生成一篇今日研习小结。”*

Agent 将自动依据 [`.agent/specs/review-summary.md`](/guide/) 规范，提取核心公式、归纳跨模态启发、并自动将新周报追加到上方归档表格中！
